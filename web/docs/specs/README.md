# Web feature specifications

Scenario-first specifications (SDD) of web features, written before the code. One folder per feature under its
area: `specs/<area>/<NNN>-<slug>/`. A specification keeps its `R-*`, `SC-*`, `TS-*` and `EN-*` ids once accepted;
the lasting description of a built feature lives in [architecture](../architecture.md), not here.
