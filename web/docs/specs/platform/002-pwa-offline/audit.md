## Findings

| ID    | Severity | Status   | Finding                                                                                                                                  | Decision                                                                                                                                                                                                          |
| ----- | -------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AF-01 | medium   | fixed    | `src/platform` held six files; `offline/` beside them breaks «files or subfolders» and the six-file limit.                               | The platform files moved into `client/` and `session/`; every import, the structure rules' paths (`src/platform/client/api`, `…/client/locale.ts`), their tests, ESLint messages, AGENTS.md and the docs updated. |
| AF-02 | low      | fixed    | `network-status.ts` would export hooks (rule `hookFileNames`).                                                                           | Plain store in `network-status.ts`, hooks in `use-network-status.ts`; the shared type and key in `queued-request.ts` (no import cycle).                                                                           |
| AF-03 | low      | fixed    | The shopping «failed tick» test answered `500`, which a queued write now retries (with backoff), so the test timed out.                  | The test answers a `400` refusal; retries of `5xx` are covered in `queued-write-api.test.ts`.                                                                                                                     |
| AF-04 | low      | fixed    | The todos «changed elsewhere» test assumed a `409` tick fails at once; under last write wins it is reread and resent.                    | The test now checks the reread and the resend with the new `If-Match`, and a new test covers the resend that succeeds.                                                                                            |
| AF-05 | low      | fixed    | A queued write offline kept `isPending` true, which would lock «Додати» and «Прибрати куплене».                                          | `isSaving` (`isPending && !isPaused`) for buttons; «Прибрати куплене» is optimistic now; «Повернути до списку» offline says it will be returned instead of waiting on the button.                                 |
| AF-06 | low      | accepted | `OfflineStatus` renders two blocks (chip and refused snackbar).                                                                          | Both read the same network state and the file is 75 lines; splitting adds a file for no clarity.                                                                                                                  |
| AF-07 | low      | accepted | The refused snackbar shows only writes made offline (or restored after a restart); a refusal of an online write shows on its own screen. | Avoids two messages for one failure; recorded in the SDD.                                                                                                                                                         |
| AF-08 | low      | accepted | A write in flight (not paused) when the app closes is not kept.                                                                          | Only paused writes can be resumed by React Query; the writes are idempotent and the module refreshes at the next start (ADR 0020).                                                                                |
| AF-09 | low      | accepted | Azure SWA does not apply route headers to requests answered by the navigation fallback; `workbox-*` cannot be a mid-path wildcard.       | Navigations are served by the service worker's precache; `/`, `/index.html` and the worker get `no-cache` directly; `injectManifest` produces no `workbox-*.js` file.                                             |
| AF-10 | info     | accepted | A kept paused write carries its optimistic snapshot (`context`) into IndexedDB.                                                          | Small for a two-person list; dropped once the write settles.                                                                                                                                                      |
| AF-11 | info     | fixed    | `src/features/notifications/push/PushCard.tsx` (notifications 002) declared two components.                                              | Split into `PushCard.tsx` (loading and error states) and `PushSettings.tsx` (the loaded card); `architecture:structure` green on the whole tree.                                                                  |

No open findings in this change's scope.
