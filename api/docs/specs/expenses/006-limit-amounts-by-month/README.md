# 006 — Limit amounts by month: each period keeps its own limit

- **Module:** Expenses
- **Type:** change (of [003](../003-budget-settings-and-limits/README.md) and [005](../005-budget-forecast-carryover/README.md))
- **Status:** implemented, audited ([audit 2026-11-27](../../../audits/2026-11-27-expenses-limit-amounts-by-month.md), findings remediated)
- **Owner:** Vitaliy
- **Created:** 2026-11-27
- **Requirements source:** Vitaliy, 2026-11-27: «делай что бы каждый месяц фиксировал свой лимит» (lowering a limit
  must not rewrite past months)
- **Frontend counterpart:** [web 006](../../../../../web/docs/specs/expenses/006-limit-amounts-by-month/README.md)
- **Decision:** [ADR 0041](../../../decisions/0041-limit-amounts-kept-by-month.md)

Until now a spending limit and the monthly limit on all expenses had one amount for every period, and the carry-over
([ADR 0027](../../../decisions/0027-limit-carry-over-like-the-sheet.md)) used today's amount for past periods too, so
lowering a limit added overspend to months that were already over. From now on an amount is kept with the month (or
quarter) it starts in: changing it applies from a chosen period onward, and earlier periods keep the amount they had.
Excluded: per-month history of the savings goal and of `LimitsFrom`, a history of names or categories of a limit.
