# C4 diagrams

Three levels: who uses the system, which deployable parts it has, and how the API is split inside.

## Context

```mermaid
flowchart TB
    family["Masha and Vitaliy<br/>expenses, shopping list, to-dos, gifts"]
    system["Home system"]
    scheduler["cron-job.org (GitHub Actions cron as backup)<br/>every 15 minutes: notifications tick, then outbox tick"]
    telegram["Telegram Bot API<br/>family bot: digests, reminders, commands"]
    push["Browser push services<br/>Web Push to the family's phones and computers"]
    sheet["Google Sheet «Учёт расходов»<br/>old expenses log, read once for the import"]
    shoppingSheet["Google Sheet «🛒 Список покупок»<br/>old list, history and dictionary, read once"]
    giftsSheet["Google Sheet «🎁 Список подарков»<br/>old gift wishlist, converted once to SQL"]
    operator["Operator<br/>runs the sheet imports"]
    todosheet["Google Sheet «✅ Список дел»<br/>old to-do list, imported once by an SQL script"]
    operator["Operator<br/>runs the sheet import"]

    family --> system
    family -->|"chats with the bot"| telegram
    scheduler --> system
    system -->|"sendMessage, setWebhook"| telegram
    telegram -->|"webhook updates"| system
    system -->|"encrypted Web Push (VAPID)"| push
    system -->|"telemetry"| insights["Azure Application Insights<br/>requests, errors, logs"]
    push -->|"notifications"| family
    operator -->|reads| sheet
    operator -->|reads| shoppingSheet
    operator -->|reads| todosheet
    operator -->|"import on a local API, then the dumped rows as SQL (DBeaver)"| system
    operator -->|reads| giftsSheet
    operator -->|"gifts import script as SQL (DBeaver)"| system
```

## Components of the API

```mermaid
flowchart TB
    host["Host.Api<br/>composition, middleware, OpenAPI"]
    blocks["BuildingBlocks<br/>results, pipeline, outbox, problems, health"]
    expenses["Expenses module<br/>expenses, incomes, savings jar, categories, budget limits<br/>with carry-over, planned expenses, month summary and forecast,<br/>sheet import<br/>schema expenses"]
    shopping["Shopping module<br/>list, cart and history (computed), departments, keywords,<br/>text parsing and matching, frequent items, summary<br/>schema shopping"]
    gifts["Gifts module<br/>gift wishlist with variants, archive, gift categories,<br/>personal details, home summary<br/>schema gifts"]
    todos["Todos module<br/>tasks with steps, statuses, priorities, categories,<br/>home page summary<br/>schema todos"]
    notifications["Notifications module<br/>linked chats, push subscriptions, digest schedule and planner,<br/>deliveries per channel, Telegram webhook and client, Web Push sender<br/>schema notifications"]
    identity["Identity module<br/>Google sign-in, family allowlist, sessions,<br/>authentication schemes, fallback policy,<br/>the current member for other modules<br/>schema identity"]
    notes["Notes module<br/>likes, dislikes and facts about each other,<br/>note categories, author from the session<br/>schema notes"]

    host --> blocks
    host --> expenses
    host --> shopping
    host --> gifts
    host --> todos
    host --> notes
    host --> notifications
    host --> identity
    expenses --> blocks
    shopping --> blocks
    gifts --> blocks
    todos --> blocks
    notifications --> blocks
    notifications -->|"Contracts: digests, completion"| todos
    notifications -->|Contracts| gifts
    notifications -->|Contracts| shopping
    notifications -->|Contracts| expenses
    gifts <-->|"integration events via outbox"| todos
    identity --> blocks
    notes --> blocks
    notes -->|"Contracts: current member (ADR 0040)"| identity
```

Update these diagrams in the same change that adds a module, an external system, or a new way of running work.
