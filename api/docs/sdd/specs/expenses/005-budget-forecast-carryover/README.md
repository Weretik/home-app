# 005 — Budget: forecast, limit carry-over, expenses outside limits

- **Module:** Expenses
- **Type:** feature
- **Status:** accepted for implementation (requirements note of 2026-11-26); implementation in progress
- **Owner:** Vitaliy
- **Created:** 2026-11-26
- **Requirements source:** `/mnt/project-files/home-app/specs/budget-forecast-carryover.md` (phase 4 note)
- **Frontend counterpart:** [web 005](../../../../../../web/docs/specs/web/expenses/005-budget-forecast-carryover/README.md)

The household's budget starts to behave like the «Бюджет» tab of the old Google Sheet: overspending a limit is taken
from the next period (carry-over), an expense can be marked «Не в лимиты» so it counts in the month's totals but not
against any limit, and the family can plan the month's expected expenses («Прогноз») and turn a plan into a real
expense in one step. The month summary gains the carry-over, the outside-limits figures and a forecast block.
Excluded: payments («Платежи»), the sheet's «План / Факт» block per category, carry-over of unspent money.
